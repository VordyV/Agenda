**Agenda** is a desktop utility. It is a simple tool to assist in development, modding, and administration of game servers, primarily for **Battlefield 2** and **Battlefield 2142** servers.

<p align="center">
    <img alt="GitHub Release" src="https://img.shields.io/github/v/release/VordyV/Agenda">
</p>
___
### Supported Platforms

- **Windows 11** (Windows 10 may work but is not a primary target)
- Probably **Windows 7**. There will be no support for this OS version, but the program may work on it.
